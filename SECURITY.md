# Security Policy

## Supported Versions
Only the latest version of Cyber Fusion Auditor is supported for security updates.

## Reporting a Vulnerability
We take the security of our tool seriously. If you believe you have found a security vulnerability in Cyber Fusion Auditor, please report it to us by opening a private issue or contacting the maintainer directly.

Please do not report security vulnerabilities through public GitHub issues.

We will acknowledge your report within 48 hours and provide a timeline for a fix if necessary.
